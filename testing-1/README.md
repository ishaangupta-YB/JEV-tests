# testing-1

Vercel AI Gateway example using the AI SDK's `experimental_evaluate` with `typesafe-ai/jev`.

## Setup

```bash
npm install
```

Create a `.env.local` file with your Vercel AI Gateway API key:

```
AI_GATEWAY_API_KEY=your_key_here
```

## Run

```bash
node --env-file=.env.local index.ts
```
